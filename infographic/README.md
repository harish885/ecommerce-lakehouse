# Azure E-Commerce Lakehouse Infographic

Run `npm install puppeteer && node render.js` from this folder to export `infographic.html` as `infographic.png` at 1200×3600 px with `deviceScaleFactor: 2`, producing a Retina-quality 2400×7200 PNG. If `ffmpeg` is installed, the same command also records the animated page and assembles `infographic.mp4`; otherwise the script prints a clear install message and exits cleanly after the PNG export.
